# mini-amaru web

Basic frontend for mini-amaru: React + TypeScript + Vite, Tailwind CSS v4, shadcn/ui, TanStack Router, Query and Table.

## Running

Start the API first (from the repo root):

```bash
make serve       # http://127.0.0.1:8765
```

Then, for the frontend:

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm run build    # generates dist/ and runs tsc -b
```

The API URL comes from `VITE_API_URL` (default `http://127.0.0.1:8765`). If the API runs on another port or origin, pass `--cors-origin` to `serve` with the frontend's origin (the default already allows `localhost:5173`).

`make package` at the root includes the compiled frontend. In the installed package,
`./mini-amaru serve` serves the UI and the API at `http://127.0.0.1:8765`, without Node.js.
For the same mode in the checkout: run `VITE_API_URL='' npm run build` in this directory and
`cargo run -- -c projects/my-project.yaml serve --web-dir web/dist` at the root.

## Structure

- `src/routes/` — file-based TanStack Router routes: `index.tsx` (dashboard), `runs.tsx` (job list), `new.tsx` (submits a prompt), `jobs.$jobId.tsx` (details, tasks, live agent log and events). `src/routeTree.gen.ts` is generated by the Vite plugin.
- `src/lib/api.ts` — REST API client (`listJobs`, `getJob`, `listEvents`, `getJobLog`, `createJob`, `resumeJob`) and TanStack Query options. Jobs update by polling; events are fetched with `after=<id>` and the log with `offset=<bytes>`.
- `src/components/ui/` — shadcn components (button, card, badge, table). Add more with `npm exec -- shadcn@latest add <component>`.
- `src/lib/utils.ts` — shadcn's `cn` helper.

## Notes

- Alias `@/*` → `src/*`.
- `@tanstack/react-table` is pinned to v8 (`useReactTable` API); v9 changed the API.

## Delivery loop in the UI

`/new` has a "Delivery loop" mode (optional milestone). A loop's job page lists its items (one job per item) with
branch → base, a **View PR** link, review and merge. On an item's page: **Create PR**, **Approve & merge** (asks for confirmation;
it is an action on GitHub) and the review message. On the loop: **Continue loop** (resumes the same job) and **Cancel**. The rules for
which buttons appear come from the server (`actions` in `GET /api/jobs/<id>`).
