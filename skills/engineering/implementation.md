# Engineering implementation

- Inspect the existing code and project conventions before editing.
- Make the smallest coherent change that satisfies the task.
- Avoid unrelated refactors and unnecessary abstractions.
- Add or update tests for changed behavior.
- Run relevant tests and report the exact commands and outcomes.
- Do not claim tests passed unless they were actually run.
- Do not commit, push, merge, or modify GitHub issues unless the task/config explicitly asks.
- Finish with a concise summary, changed files, tests, and remaining risks.
